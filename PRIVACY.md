# Политика конфиденциальности

Это политика Telegram-бота для учёта личных трат. Бот работает по приглашениям: пользоваться им
можно только после перехода по ссылке-приглашению от администратора.

## Что хранится

- Ваш числовой Telegram id. По нему бот узнаёт вас; ваш @username и номер телефона не хранятся.
- Ваше имя в Telegram, если вы записываете траты в группе: им подписаны ваши траты в отчётах
  группы.
- Траты: сумма, валюта, описание, дата и категория.
- Чеки: сумма, дата, фискальный номер чека, ссылка из QR-кода, название магазина и позиции чека.
- Настройки: часовой пояс, валюта по умолчанию, категории, бюджет и лимиты.
- Пожертвования: сколько звёзд, когда и идентификатор платежа Telegram.

## Где

Данные лежат на сервере (VPS) в Европейском союзе, в базе SQLite. Раз в сутки делается резервная
копия базы. Хранятся последние `BACKUP_KEEP` ежедневных копий (по умолчанию 7) и
`BACKUP_KEEP_WEEKLY` воскресных (по умолчанию 4), остальные удаляются. Так копия живёт не дольше
большего из двух сроков: `BACKUP_KEEP` дней или `BACKUP_KEEP_WEEKLY` недель (по умолчанию 28 дней).

## Кто может их прочитать

Администратор бота, у которого есть доступ к серверу. Исключение — зашифрованный личный учёт
(«Шифрование» в /settings): его траты зашифрованы ключом, который открывается только вашим
паролем или кодом восстановления, и администратор их прочитать не может.

## Что уходит с сервера

- **Налоговые сайты** — только для чеков, которые вы прислали. Бот запрашивает магазин и позиции
  чека по ссылке из его QR-кода:
  - `suf.purs.gov.rs` — чеки из Сербии;
  - `mapr.tax.gov.me` — чеки из Черногории.
- **Народный банк Сербии** (`webappcenter.nbs.rs`) — бот раз в час скачивает курсы валют. Никаких
  данных пользователей НБС не получает.

Больше бот ни с какими сайтами не связывается.

## Роль Telegram

Все сообщения идут через Telegram. Telegram видит переписку с ботом и хранит её по своим
правилам: https://telegram.org/privacy. Удаление аккаунта в боте не удаляет сообщения в Telegram —
их можно удалить в самом чате. Пожертвования звёздами проходят через платежи Telegram: бот получает
только сумму в звёздах и идентификатор платежа.

## Удаление

Команда /delete_account удаляет личный учёт целиком: все траты, чеки, категории, бюджет и
настройки. Траты в общих учётах групп остаются, чтобы не менять итоги других участников, и
показываются как «удалённый участник». Записи о пожертвованиях тоже остаются: без них нельзя
вернуть платёж. В резервных копиях данные остаются, пока эти копии не удалятся: по умолчанию до
28 дней (см. «Где»).

## Чего бот не делает

- Не показывает рекламу.
- Не продаёт и не передаёт данные третьим лицам.
- Не использует аналитику и трекеры.
