Добавьте бота в группу — и у группы появится свой общий учёт, названный по группе, с вашими
часовым поясом и валютой. Добавить бота может только тот, кто уже пользуется им; добавленный
кем-то другим, бот выйдет из группы. Личные траты из переписки с ботом в группу не попадают.

## Траты в группе

Каждый участник пишет траты сам, как в личной переписке: «450 кафе». Трата записывается на имя
автора. Узнанную трату бот отмечает реакцией ✍, без ответа, — поэтому у «450 кафе» ниже ответа
нет. Трату в «Другое» бот подтверждает карточкой с кнопкой «Удалить».

Если сумма в конце, как в «Чайник 3200», бот сначала спросит «Записать?». Ответить может только
автор сообщения; без ответа вопрос исчезнет через 15 минут. Ниже Борис нажал «Записать», и
вопрос стал карточкой:

- `/today`, `/week`, `/month` — итоги группы по категориям и по участникам.
- `/settle` — кто кому должен, если делить траты группы поровну. «Перевёл» записывает перевод,
  «Я тоже участвую» добавляет участника, который ещё ничего не записал.
- `/budget` — бюджет группы: сколько осталось на сегодня и до конца периода.
- `/export` — все траты группы файлом, с колонкой автора.
- `/tags` и `/tag` — метки группы, как в личной переписке.
- `/card` ответом на сообщение с тратой показывает её карточку.
- `/settings` — для того, кто добавил бота: ссылка на настройки группы в личной переписке.
  Там же задаётся бюджет группы.

«Удалить» и «Вернуть» на карточке работают только для автора траты. `/help` в группе — памятка
