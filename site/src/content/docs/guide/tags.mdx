Метка собирает траты одной поездки или проекта поверх категорий. Добавьте к трате слово с #:
«450 кофе #отпуск». Меток может быть до пяти на трату; в описание они не попадают. «Изменить» →
«Метки» на карточке заменяет метки, а «-» убирает их.

Чтобы не писать метку каждый раз, отправьте `/tag отпуск`: метка добавится ко всем новым тратам,
пока вы не нажмёте «Снять метку». `/tag` без слова покажет, какая метка включена.

`/tags` показывает метки учёта с суммами за всё время, начиная с недавних. Кнопка метки открывает
её отчёт по категориям, с числом трат и датами первой и последней:

<Chat name="tags" />

В Telegram у отчёта по метке есть и кнопка «📈 Диаграмма»: кольцо категорий метки, как у месяца.
