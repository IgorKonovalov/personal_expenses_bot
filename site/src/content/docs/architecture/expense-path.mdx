1. **Получение.** Бот забирает обновления долгим опросом. Первые промежуточные слои ловят
   ошибки, отмечают медленные обновления и отбрасывают поток сообщений сверх лимита ещё до
   чтения базы.
2. **Ветвление.** Обновления групп и личных чатов идут в разные цепочки обработчиков и не
   смешиваются
   ([ADR-0014](https://github.com/IgorKonovalov/personal_expenses_bot/blob/main/docs/adrs/0014-group-chats-bind-to-shared-ledgers.md)).
   В личном чате проверяется доступ по приглашению
   ([ADR-0024](https://github.com/IgorKonovalov/personal_expenses_bot/blob/main/docs/adrs/0024-admission-lives-in-the-database-via-invite-codes.md))
   и первое знакомство.
3. **Команды раньше текста.** Команды и точные надписи кнопок меню разбираются первыми. Любой
   другой текст — ответ на открытый вопрос бота
   ([ADR-0009](https://github.com/IgorKonovalov/personal_expenses_bot/blob/main/docs/adrs/0009-persisted-flow-sessions.md)),
   ссылка на чек, СМС банка или попытка записать трату.
4. **Разбор.** Domain читает сумму по единому правилу для всех локалей
   ([ADR-0004](https://github.com/IgorKonovalov/personal_expenses_bot/blob/main/docs/adrs/0004-amount-parsing-rule.md)),
   слова валют, суффикс «к» и сумму в конце
   ([ADR-0046](https://github.com/IgorKonovalov/personal_expenses_bot/blob/main/docs/adrs/0046-currency-words-thousands-suffix-and-amount-last-text.md)).
   Неоднозначную сумму бот не угадывает, а спрашивает.
5. **Категория.** Сначала — куда этот учёт раньше относил то же описание, потом ключевые слова
   ([ADR-0008](https://github.com/IgorKonovalov/personal_expenses_bot/blob/main/docs/adrs/0008-category-suggestion-from-history.md)).
6. **Запись.** У траты есть ключ источника `tg:<чат>:<сообщение>` с уникальным индексом.
   Повторная доставка того же обновления упирается в него и возвращает уже записанную трату.
7. **Ответ.** Текст карточки берётся из модуля текстов и уходит как HTML только через один шов,
   который экранирует подстановки
   ([ADR-0012](https://github.com/IgorKonovalov/personal_expenses_bot/blob/main/docs/adrs/0012-html-rendering-seam.md)).
   Карточка становится якорем экрана: кнопки под ней правят её на месте
   ([ADR-0040](https://github.com/IgorKonovalov/personal_expenses_bot/blob/main/docs/adrs/0040-expense-card-inside-a-screen-anchor.md)).
